# じゃんたま配信オーバーレイ（GitHub Pages版・サーバー不要）

雀魂（じゃんたま）配信用のOBSオーバーレイです。HTML/JS/CSSのみで動き、サーバーは不要です。

- コントロール: https://mizuno-kazunari.github.io/jantama-overlay/control.html
- オーバーレイ: https://mizuno-kazunari.github.io/jantama-overlay/overlay.html
- 立直検知: https://mizuno-kazunari.github.io/jantama-overlay/detector.html

## 機能
- 段位戦モード: 段位ゲージ（色・位置・サイズ調整、昇段/降段演出）、着順履歴（4-1-1-3 をバッジ表示）
- 友人戦モード: ルームID表示、参加型ルールのテロップ（流れる/固定）
- 共通: 立直カットイン（透過WebM）、立直中ループ再生、表示位置・拡大率・表示切替

## 仕組み
各ページは同じブラウザ（同じオリジン）内で `BroadcastChannel` と `localStorage` を使って連動します。
OBSの「カスタムブラウザドック」と「ブラウザソース」は同じブラウザプロファイルを共有するため、**コントロール画面をOBSのドックで開けば、オーバーレイがリアルタイムで更新されます。**
（普通のChromeで開いたコントロール画面からは、OBS内のオーバーレイは操作できません。）

## OBSの設定
1. ソース「＋」→「ブラウザ」→ URL に `overlay.html` のURL、幅 1920 / 高さ 1080。雀魂の画面より上に配置。
   音を出す場合は「OBSで音声を制御する」をON。
2. メニュー「ドック」→「カスタムブラウザドック」→ 名前「じゃんたま操作」、URL に `control.html` のURL を追加。
3. （任意）同様に `detector.html` もドックに追加。

### 動画（カットイン/ループ）
- 標準でサンプル動画（media/）を同梱。
- 「取り込み」: 手元の透過WebMをドック内のIndexedDBに保存（同じOBS内のオーバーレイで再生可能）。
- 「URL指定」: ネット上の動画URLを指定（どこからでも再生可能）。リポジトリの `media/` に置いてpushする方法もおすすめ。
- 透過動画は WebM（VP9 + アルファ）推奨。

### 予備: 設定入りURL
コントロールの「設定入りオーバーレイURLをコピー」で、現在の見た目（段位・履歴・ルームID・色・位置など）を埋め込んだURLを作れます。ドックが使えない場合にブラウザソースに貼ってください。ただしこの方法では**自動更新・立直演出の連動はされません**。

## 立直の自動検知（detector.html）
雀魂のウィンドウを取り込み、登録した「立直マーク」画像と照合して立直中かどうかを自動判定します。範囲指定や色の調整はほぼ不要です。

### 使い方（3ステップ）
1. **ウィンドウを選ぶ**: 「ウィンドウを選択」→「ウィンドウ」タブで雀魂を選択。
   - OBSドック内でウィンドウ選択が出ない／真っ黒になる場合は、OBSの「仮想カメラ開始」→「OBS仮想カメラ/カメラを使う」。
2. **立直マークを登録する**:
   - 「立直中のスクショを読み込む」（Ctrl+V貼り付け、または「今のウィンドウ画面を使う」も可）。
   - 画像の上で**自分の立直棒（1000点棒）をドラッグで囲み**、「この範囲を登録」。棒の少し外側まで含めると安定します。複数登録できます（卓デザイン違いなど）。
   - （任意・推奨）「立直していないスクショ」を読み込むと、しきい値を2枚のスコアの中間に自動設定します。
   - 「この画像で照合テスト」で、読み込んだ画像で検出できるか確認できます。
3. **検知開始**: プレビューに探索範囲（黄色点線）と一致位置（赤枠＝検出）、スコアとしきい値のバーが表示されます。

### 仕組み
- 解析用にフレームを幅640pxのグレースケールに縮小し、正規化相互相関（ZNCC）でテンプレートを照合（外部ライブラリ不要、1フレーム約20〜30ms）。
- テンプレートは「元スクショに対する相対位置・大きさ」で保存。ウィンドウサイズが変わっても予想サイズを計算し、さらに0.8〜1.25倍の範囲で探すので追従します（上下左右の黒帯にも対応）。
- 初期設定は「登録位置の周辺だけ探す」ので、**対面など他家の立直棒には反応しません**（詳細設定で画面全体にも変更可）。一度見つけたらその近くだけ探し、定期的に周辺全体を再探索します。
- 誤動作防止: 3回連続で検出したら立直カットイン → ループ再生。15回連続（約3秒）で見えなくなったら立直終了。クールダウン8秒、カットイン後6秒は終了判定しません（いずれも詳細設定で変更可）。手動で立直終了した場合、棒が一度消えるまで再発火しません。
- テンプレートと「立直なし」スクショはそのブラウザ（OBSドック）内のlocalStorageに保存されます。普通のChromeとOBSドックでは保存先が別なので、**登録はOBSドックで開いた検知ページで行ってください。**

### 注意
- **OBSと連動させるには、detector.html もOBSのカスタムブラウザドックで開く必要があります。**（普通のChromeで開いた場合、OBS内のオーバーレイには通知が届きません。テスト・調整用途には可）
- 仮想カメラ入力にはオーバーレイも映るので、カットインやループ動画が立直棒に重ならない配置にしてください。
- 誤検知が多い → テンプレートのしきい値を上げる／立直なしスクショを登録。検出されない → しきい値を下げる／別の場面のスクショでテンプレートを追加。
- 手動の「立直カットイン」「立直終了」ボタンはいつでも使えます。

### テスト
`node test/synth.js` で合成画像（偽の卓画面を8種類のウィンドウサイズで描画）による照合テスト、`python3 test/e2e.py` でブラウザE2Eテスト（要 `node test/gen.js` と `python3 -m http.server 8765`）を実行できます。

## ローカルで試す
`python3 -m http.server` などで本フォルダを配信し、`control.html` と `overlay.html` を同じブラウザの別タブで開くと連動します。
